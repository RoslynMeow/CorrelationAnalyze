# CSV 关联性分析看板（Association Analyzer）

一个**纯前端、可离线**的 CSV 关联分析工具：拖入任意 CSV，自动识别字段类型，生成相关矩阵、目标关联排序、散点拟合、分组对比、成对关系和文字结论。

当前是**单文件版本**（HTML 内联了 Plotly），后续计划迁移到 npm 工程（React / Vue 待定）。

> 本文件用于交接：换电脑、移动文件夹、隔一段时间继续开发时，先读这里。

## 2. 怎么用

1. 双击 `correlation-analysis.html`（Chrome / Edge / Firefox 现代版本）。
2. 把 CSV 拖进居中卡片，或点击卡片选择文件。
3. 载入后进入分析界面，右上角「更换 CSV」可随时换数据。

- 断网可用；文件不会上传，全部计算在浏览器本地完成。
- 支持编码：UTF-8 / UTF-8 BOM / GBK(GB18030) / UTF-16 LE/BE。
- 支持分隔符：`,` `;` Tab `|`（自动探测）。
- 数据上限：读取前 100,000 行；散点抽样 6,000 点；成对图抽样 3,000 行。

如果通过 `file://` 打开，主题偏好（localStorage 键 `ca-theme`）在部分浏览器里不保存，其余功能不受影响。

## 3. 当前功能清单

| 页签 | 内容 |
|---|---|
| 关联总览 | 数据规模 KPI、全部变量对的关联强度 Top 10、自动文字解读 |
| 相关矩阵 | 数值变量 Pearson / Spearman 切换；类别变量 Cramér's V 矩阵；下三角遮罩、数值标注 |
| 目标关联 | 选一个目标列，其余列按关联强度排序；自动区分 r / ρ / η / V；绿=正、红=负、蓝=无方向 |
| 散点拟合 | 任选 X/Y/颜色/气泡大小；线性拟合线；同时给出 Pearson r 和 Spearman ρ；日期列可作时间轴 |
| 分组对比 | 按任意分组列批量画箱线图，可多选数值变量，小样本自动显示散点 |
| 成对关系 | SPLOM 矩阵图，最多 6 维，按类别着色 |
| 分析结论 | 数据概况、最强关联、目标因素、类别维度关联、冗余变量、数据质量 |
| 数据预览 | 表格分页、全列搜索、列画像、导出当前数据 CSV |

全局能力：深浅色主题、响应式（320px 起）、图表缩放/悬停/图例开关、单图导出 PNG。

关联度量口径：

- 数值 × 数值：**Pearson r**（默认）或 **Spearman ρ**（对数值列取平均秩后求 Pearson）
- 数值 × 类别：**相关比 η**（η = √(组间平方和 / 总平方和)，0–1，无方向）
- 类别 × 类别：**Cramér's V**（基于卡方，0–1，无方向）
- 缺失值：逐对剔除（pairwise complete），n < 3 视为不可计算；V 需要 n ≥ 4 且至少 2×2

### 4.2 结论

**notebook 有、网页还缺的 3 个视图：**

1. 单变量分布（直方图 + KDE，可分组叠加）
2. 类别计数图（countplot，可堆叠子组 / 百分比）
3. 雷达画像（按组标准化后的多维对比）

**网页比 notebook 强的：**

- 通用性：任意 CSV，不写死列名；自动识别数值/类别/日期/ID
- 统计：多出 Spearman ρ、Cramér's V、相关比 η，能处理类别目标
- 交互：悬停、缩放、图例开关、单图导出、深浅色
- 工程：缺失/重复/常量列检查、搜索分页、导出 CSV、响应式、离线单文件

**notebook 比网页强的地方：**

- 可复现：代码即分析记录，能改参数、能版本管理
- 分析预设：notebook 里"哪 8 个指标、哪 3 组散点、雷达用哪 9 维"体现了分析意图；网页目前是通用选择器，没有预设
- 报告：notebook 可以直接导出整篇分析，网页只能一张张导出图

### 4.3 设计建议（供讨论）

把 notebook 的"分析意图"产品化，而不是简单加 3 个图表页：

- **预设模板**：例如"学生心理健康模板"自动勾选关键指标、分组列、雷达维度；也允许保存自定义预设
- **报告模式**：一键把当前配置的图表 + 结论拼成可打印页面（HTML/PDF）
- **分布补齐**：分布页同时放直方图/KDE/箱线，支持按组叠加
- **雷达补齐**：0–1 归一化 / Z-Score 两种标准化
- **类别补齐**：countplot + 百分比堆叠 + 不平衡比

## 5. 数据处理与实现说明（单文件版）

### 5.1 类型推断

对每一列（去掉空值后）：

- 全部可转数字 → `number`（支持千分位、货币符号、百分号）
- 全部符合日期格式 → `date`
- 其他 → `category`
- `uniqueCount === 总行数` 且列名是 `id` / `编号` / `序号` / `index` → 视为 ID，排除出统计
- 空值识别：空串、`NA`、`N/A`、`NaN`、`null`、`none`、`-`、`--`、`?` 等

### 5.2 可分组列

取值数 2–40 的列；数值列额外要求 ≤12 个取值（如学年 1–4 可分组，年龄 17–29 不默认当分组）。

### 5.3 计算上限（性能保护）

- 关联总览：最多前 40 个变量、两两组合
- 类别矩阵：最多 20 列，每列 ≤25 个取值
- 目标变量：类别列 ≤50 个取值
- 散点：最多 6,000 点；SPLOM：最多 3,000 行
- 读入：最多 100,000 行

### 5.4 代码在哪里

单文件里业务代码在 HTML 底部 `<script>` 中，搜索 `1. 通用工具` 可定位。结构依次是：

1. 工具函数 → 2. CSV 解析/解码 → 3. 数据模型 → 4. 图表基础设施 → 5. 启动/落地页 → 6–13. 各页签 render 函数 → 14. 文件载入与事件

Plotly 是文件开头的一大段压缩代码（搜索 `plotly.js v2.35.2 (inlined)`）。**不要在这段里改东西**；迁移到 npm 后直接用依赖包即可。

### 5.5 响应式断点

- `≤900px`：双栏变单栏，隐藏顶部文件名标签
- `≤760px`：表格切换成"标签—值"卡片（消除横向滚动）；图表高度/边距缩小；长变量名截断（悬停看全名）
- `≤420px`：KPI 两列

跨断点时 JS 会重绘当前页签（处理手机横竖屏）。

### 6.1 为什么迁移

- 现在所有逻辑塞在一个 HTML 里，改一个页签要在大文件里找，没法做单元测试

### 6.2 技术栈选项（待你确认）

| 方案 | 优点 | 备注 |

| **Vue 3 + Vite + TypeScript** | 单文件组件和现在的"模板字符串 + render 函数"最接近，迁移最省事；Pinia 状态简单 | 个人维护更轻松 |

- CSV：`papaparse`（大文件 worker 模式）+ 自写编码探测（保留现在的 GBK/UTF-16 逻辑）
- 表格：20 列以内自己做也行；React 可用 TanStack Table

- 测试：Vitest，重点测 `stats.ts`（Pearson/Spearman/Cramér's V/η 与 notebook / scipy 对齐）

### 6.4 迁移步骤

1. 新建 Vite 工程，搬入 `lib/` 四个文件并 TS 化（先写 Vitest，和现有结果对齐）
2. 抽出 `PlotlyChart` 组件：入参 `traces/layout`，统一主题、响应式、导出
3. 先迁「上传 → 数据表 → 相关矩阵 → 目标关联」四条主链路
4. 再迁散点、分组、成对、结论
5. 补 notebook 缺的 3 个视图（分布 / 类别计数 / 雷达）
6. 最后做预设模板、报告导出、Worker、性能优化

### 6.5 构建与"双击可运行"

npm 工程的默认产物需要**静态服务器**（`npm run build` 后 `npx serve dist`，或部署 GitHub Pages / Nginx），因为 ES Module 在 `file://` 下受限。

如果仍然想要"双击就能用"的便携版，加 `vite-plugin-singlefile`（并设 `base: './'`）：

```
npm run build          # 常规 dist/
npm run build:single   # 单文件 dist/index.html，可直接分发
```

两个产物可以并存：单文件给分享/离线，常规构建给部署。
